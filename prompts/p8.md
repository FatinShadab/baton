Add voice-to-text for the task box.
src/voice.ts: transcribe(audio: Buffer, mime: string) -> string. POST
https://api.elevenlabs.io/v1/speech-to-text with header xi-api-key (from
secrets), multipart FormData with fields model_id="scribe_v2" and file=Blob
(filename "audio.webm"). Return response.text. 30s timeout, clear error messages.

Recording, primary path: in the webview, a mic button toggles MediaRecorder via
navigator.mediaDevices.getUserMedia({audio:true}) (pulsing red dot while recording).
On stop, base64-encode the blob, postMessage it to the extension, which calls
transcribe() and replies with the text, which is appended to the textarea.

Fallback path (IMPORTANT, getUserMedia may be denied in VS Code webviews): if
getUserMedia rejects, the extension starts a tiny http server bound to
127.0.0.1 on a random port with a one-time token. It serves a minimal page
with Record/Stop (MediaRecorder) that POSTs the blob to /audio?token=...; the
extension transcribes it, closes the server, and sends the text to the panel.
Open this page with env.openExternal and show "Recording in your browser, close the tab when done".
Add the ElevenLabs key to baton.setKeys if not already there.
Optional: if the transcript starts with "route" or ends with "go", auto-trigger Route task.
Done when: speaking "update the readme with install steps" fills the box with that text.
