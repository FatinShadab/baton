Implement the AI router in src/router/.
gemma.ts: use the @google/genai package, model "gemma-4-26b-a4b-it", key from
secrets. Call models.generateContent with a system prompt defining the Route JSON
schema and enums, "respond with JSON only", responseMimeType "application/json".
If the API rejects the system instruction or JSON mode, fold the instructions
into the user prompt and strip ``` fences before JSON.parse. 8s timeout.
ollama.ts: POST https://ollama.com/api/chat, header Authorization: Bearer <key>,
body {model: "gemma4:31b", messages, stream:false, format:"json"}. Make the model
tag a constant at the top of the file (cloud tag may be "gemma4:31b-cloud"). 8s timeout.
index.ts: routeTask(task, ctxSnippet) tries gemma -> ollama -> rules. Each
tier's output is validated with the zod Route schema; failure or timeout falls
to the next tier. Return {route, tier}. Cache results by task text in memory.
Then apply policy.decide(). Show in the UI which tier answered ("via Gemma
(AI Studio)" / "via Ollama" / "via rules"), and save a TaskRecord.
Done when: it routes via Gemma with a valid key, via Ollama with a bad Google key, and via rules with both keys bad.
