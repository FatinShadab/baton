# Date parser demo

A tiny Node app for Baton's live task: **“Fix the failing test in the date parser.”**

Run `npm test` here to see one failing test. The parser accepts `YYYY-MM-DD` and
should return midnight UTC on that date. Fix `date-parser.js`, rerun the test,
and use Baton's **Mark done** action to save the outcome.

Requires Node 18 or newer. No dependencies or install step are needed.
